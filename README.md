# 电商用户行为分析
本项目基于一份公开的电商用户行为数据集,某电商平台在 7 天内产生了 74 万条用户行为日志，覆盖 10,739 名用户，使用 MySQL + Python 进行电商用户行为分析，完成从原始数据到分析结论的完整链路：使用 6 张彼此独立的表格，构建 34 列分析宽表，并在此基础上完成探索性分析,最终给出四条可落地的运营动作。

# 数据来源
基于公开电商用户行为数据集，共 6 张表：行为明细 75.8 万行、用户人群标签 10,739 条、类目 5,357 条、商品 32.8 万条、商品-类目关系、用户评论 1.46 万条，时间跨度为 2024-05-29 至 06-04。

# 技术栈
- 数据提取与清洗：MySQL（多表 LEFT JOIN、ROW_NUMBER() 窗口函数去重、CASE 派生时间与行为字段）
- 探索性分析：Python（Pandas 分组聚合与比率计算、Matplotlib 可视化）
- 指标设计：事件级 / 用户级双口径、贝叶斯收缩偏好指数、lift
- 分析宽表：dwd_user_behavior，34 列，覆盖用户 / 商品 / 类目 / 行为 / 时间 / 金额 / 文本 7 个主题域
  
# 核心业务发现（SQL 洞察）
- 流失点在加购之前，不在结算：按人数口径，30.6% 的浏览用户（3,267 人）从未加过购物车；而加购用户中 60.9% 最终完成购买，购物车放弃率只有 39.1%。结算链路是通畅的，钱不该继续砸在结算页的优惠上。
- 同一份数据必须分两个口径看：按次数，100 次浏览只换来 6.4 次加购；按人数，69.4% 的浏览用户至少加购过一次。差异来自人均 62 次的高频浏览，判断流失只能用人数口径。
- 流量与转化严重背离：耳机 3,349 人浏览、仅 78 人购买（2.33%），而 Lightning转接头达 20.25%、桌游卡牌 19.10%。高流量低转化的集中在 3C 小件（同质化、可比价强），高转化低流量的共同特征是需求明确、决策链短。
- 复购是跨品类的：购买 2 次以上的用户占 56.0%，但同款复购率只有 6.8%。用户愿意反复下单，却几乎不回头买同一件，单品复购提醒基本无效。
 
# 用户分层与偏好
- 加购次数比浏览时长更能区分价值：从 0 次到 3 次以上购买，人均加购从 1 次增至 4 次（4 倍），人均浏览只增长 1.9 倍。未购买用户 4,629 人（43.1%）是最大的单一增长池。
- 人群标签不适合筛「高转化」：9 个主群体转化率都在 52.9%～60.6%，差距不到 8 个百分点，按标签圈人没有多少价值。
- 差异藏在长尾品类：用贝叶斯收缩（SHRINK = 20）抑制小样本虚高后，自由职业者 × USB风扇偏好指数 1.66、游戏宅 × 文件夹 1.58；男性偏好空气清新剂（1.43）、女性偏好保温杯（1.30）。销量榜前列的衣架、手机壳属全民共性需求，做定向投放意义不大。
  
# 活跃时间规律
- 流量双峰：早间 8 点 66,014 次行为，晚间 20–23 点 3.2 万～3.8 万次；凌晨 0–5 点同样占三成流量（6 小时 22.6 万次）。
- 购买率与流量并不同步：0 时 2.57%、20 时 2.56% 为全天高位，14 时只有 1.00%；凌晨 0–5 点购买率 2.22%，还高于全天均值 1.96%。
- 周内存在错位：周一行为量最大（153,002 次）但购买率最低（1.85%），周五购买率最高（2.17%）。周一多为惯性浏览，周五才是决策日。
  
# 业务落地与产出
- 加购前置：详情页首屏上「加购锁价 / 加购送券」，对加购后 24 小时未支付的用户做定向催付，把 39.1% 的弃购率压下去。
- 曝光再分配：耳机、LED台灯、迷你蓝牙音箱收缩无差别曝光，改做「参数对比 + 评价摘要」内容页；转接头、桌游卡牌、移动电源增加首页与搜索推荐位。
- 跨品类替代单品：放弃同款复购提醒，按人群偏好做搭配推荐；4,629 名未购用户用「首单低门槛 + 品类尝新」组合券激活。
- 排期跟转化率走：资源集中 20–23 点，周五做转化型活动、周一做内容种草；凌晨流量用「次日提醒」承接，不做深夜促销。
