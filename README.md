# 电商用户行为分析
本项目基于一份公开的电商用户行为数据集,某电商平台在7天内产生了74万条用户行为日志，覆盖10739名用户，使用MySQL+Python进行电商用户行为分析，完成从原始数据到分析结论的完整链路：使用6张彼此独立的表格，构建34列分析宽表，并在此基础上完成探索性分析,最终给出四条可落地的运营动作。

# 数据来源
基于公开电商用户行为数据集，共6张表：行为明细75.8万行、用户人群标签10739条、类目5357条、商品32.8万条、商品-类目关系、用户评论1.46万条，时间跨度为2024-05-29至06-04。

# 技术栈
- 数据提取与清洗：MySQL（多表 LEFT JOIN、ROW_NUMBER()窗口函数去重、CASE 派生时间与行为字段）
- 探索性分析：Python（Pandas分组聚合与比率计算、Matplotlib可视化）
- 指标设计：事件级/用户级双口径、贝叶斯收缩偏好指数、lift
- 分析宽表：dwd_user_behavior，34列，覆盖用户/商品/类目/行为/时间/金额/文本 7 个主题域
  
# 核心业务发现（SQL 洞察）
- 客户流失点在加购之前，不在结算层面：按用户数去算，30.6% 的浏览用户（3267人）从未加过购物车；而在加购用户中82.5%最终完成购买，购物车放弃率只有39.1%。结算的链路是通畅的，可以得知钱不应该继续砸在结算页的优惠上。
- 同一份数据我们分两个口径看：按浏览次数，100 次的浏览只能换来6.4次加购；按用户数去看，69.4%的浏览用户至少加购过一次。根本的差异主要来自人均62次的高频浏览量，从而我们判断流失后续只能用用户人数口径去分析。
- 不同产品品类流量与转化严重背离：耳机品类有3349人浏览、仅78人购买（2.33%），而Lightning转接头转换率高达20.25%、桌游卡牌高达19.10%。高流量低转化的集中在3C小件（同质化、可比价强）等特点产品上，并且可以得出高转化低流量的产品共同特征是需求明确、决策链短。
- 复购从数据看出跨品类的复购：购买2次以上的用户占56.0%，但同款复购率只有6.8%。用户愿意反复下单，却几乎不回头买同一件，单品复购的提醒分析基本无效。
 
# 用户分层与偏好
- 通过加购次数比浏览时长更能去区分用户价值：从0次到3次以上购买，人均加购从1次增至4次，人均浏览只增长1.9倍。未购买用户4629人（43.1%）是最大的单一增长池。
- 人群标签不适合筛选高转化的用户人群：9个主群体转化率都在52.9%～60.6%，差距不到8个百分点，按标签圈人分析没有多少价值。
- 差异藏在长尾和腰部品类：用贝叶斯收缩（SHRINK=20）抑制小样本虚高后，自由职业者 × USB风扇偏好指数1.66、游戏宅 × 文件夹1.58；男性偏好空气清新剂（1.43）、女性偏好保温杯（1.30）。人群差异集中在腰部品类，性别差异落在长尾品类。
  
# 活跃时间规律
- 流量双峰：早间8点66014次行为，晚间20–23点3.2万～3.8万次；凌晨0–5 点同样占三成流量（6小时22.6万次）。
- 购买率与流量并不同步：0时2.57%、20时2.56%为全天高位，14 时只有1.00%；凌晨0–5点购买率2.22%，还高于全天均值1.96%。
- 周内存在错位：周一行为量最大（153002次）但购买率最低（1.85%），周五购买率最高（2.17%）。周一多为惯性浏览，周五才是决策日。
  
# 业务落地与产出
- 加购前置：详情页首屏上(加购锁价/加购送券)，对加购后24小时未支付的用户做定向催付，把39.1%的弃购率压下去。
- 曝光再分配：耳机、LED台灯、迷你蓝牙音箱收缩无差别曝光，改做(参数对比 + 评价摘要)内容页；对高转化品类增加首页与搜索推荐位，测试流量弹性。
- 跨品类替代单品：放弃同款复购提醒，按人群偏好做搭配推荐；4629名未购用户用(首单低门槛 + 品类尝新)组合券激活。
- 排期跟转化率走：资源集中20–23点，周五做转化型活动、周一做内容种草；凌晨流量用(次日提醒)承接，不做深夜促销。
